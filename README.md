# 🐓 Petukhub

_**Платформа для тех, кто не пишет код, а красиво клацает.**_  
**Petukhub** — это хранилище вайб-кодинга, референсов и кривых решений, которые не валидны, не логичны, но почему-то работают и даже нравятся.

> _“Петух клюнул — задеплоил.”_  
> — народная инженерная

---

## 🤔 Что это?

Petukhub — это не дизайн-система.  
Это **вайб-система**.

Здесь мы:
- копим хаки, не удосужившись их проверить
- клонируем компоненты из продов, потому что «вот это красиво»
- пишем логику в стилях и называем это фреймворком
- делаем из Notion sacred UI source of truth
